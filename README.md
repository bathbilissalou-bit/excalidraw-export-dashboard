# Excalidraw Export Dashboard

Cycle 2 prototype for tracking brand visibility across exported/shared content.

## Run locally

```bash
npm install
npm run dev
```

## Deploy

This project can be deployed directly to Vercel.

## MVP included
- Total exports
- Attributed exports
- Unattributed exports
- Brand Visibility Rate
- Open/Edit click count
- Export format filter
- Attribution status filter
- Visibility trend chart
- Performance-by-format table
- Quick insights

All data is mock data for prototyping.
